# Scam Detective

A Next.js starter homepage for Scam Detective.

## Run locally

1. Install Node.js (LTS) from https://nodejs.org
2. Open this folder in a terminal.
3. Run `npm install`
4. Run `npm run dev`
5. Open http://localhost:3000

## Deploy

Push the project to a GitHub repository, then import that repository into Vercel.

## Important

This is a visual homepage starter only. The AI investigation workflow, file uploads, authentication, privacy controls, rate limiting, and provider integrations have not been implemented. Do not collect real user evidence until those features and retention practices have been designed and tested.
